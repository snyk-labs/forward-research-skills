# Short-form copy rules

Generic rules; restate them in the working doc with the study's own names and metrics, taken from the narrative guideline's guardrails.

- **Lead with the finding, not a winner.** If the top systems are not separable on this reference set, no asset or post says one "beats" another, in either direction.
- **Name the full configuration** (harness or product plus model and settings), shortest unambiguous form on the image, full name in the alt text. Results belong to the configuration, not the bare model.
- **Keep the paper's wording ceiling.** "Consistent with" stays "consistent with"; a single supplementary run stays "in one supplementary run".
- **No significance language** and no causal claim the paper doesn't make.
- **Metric families stay apart.** A system scored under a different metric is never ranked against or combined with the others.
- **Unmatched outputs** are described as the paper describes them (for detection studies: "outside the reference set", not "false positives" or "noise").
- **Unmeasured is not zero.** A system with no measured per-run cost gets a label, never a $0 bar; name what the study doesn't measure (licences, infrastructure).
- **Single runs are single observations.** Say "in this run" for ratios and timings when each cell ran once.
- **One system of its category tested means one system named.** Write the system's name where a number is attached, not the category.
- **Same treatment for every system.** The same verbs, caveats and prominence for comparable results, whichever system produced them, the authors' product included.
- **Every asset carries one caveat line**, the one that keeps that asset honest.
